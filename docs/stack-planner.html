The whole stack as a single plan: six stages, left to right, in the order you actually bring the system up — data, API, AI & realtime, client, the optional voice process, then ship. Every version is the one pinned in the repository, every gate is one that really refuses, and the bottom lane holds what is present but deliberately not on the roadmap.

The four commands

docker compose up -d → alembic upgrade head → uvicorn app.main:app --port 3300 → npx ng serve. Stage 5 only if you need voice.

Where the ports are

Postgres 5433 on the host, API 3300, web 4200 proxying /api straight through. Nothing else listens.

Two rules that outrank the plan

Student PII never reaches a remote model unbidden, and staff scope is decided by role — a MENTOR with no group sees nobody, never the whole programme.
