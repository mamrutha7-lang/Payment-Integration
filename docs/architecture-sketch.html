and how the AI interview flows

field notes · apps/web + apps/api-py · Aug 2026

Three drawings. The first is the whole machine; the yellow marker traces the only path this page cares about: a student's voice going up to the model and a record coming back down. The second is the turn loop that makes it feel like a real interviewer. The third is how an interview ends and what it leaves behind.

pencil = the whole stack marker = the AI-interview path red = refusals & close codes

fig. 1The whole machine, interview path in marker

Four processes at most, and the fourth is optional. The interviewer is not a fifth process — the relay lives inside the FastAPI worker on :3300. The old LiveKit voice stack stays drawn in dashed pencil: mounted, callable, no button in the UI. It's the rollback path, not dead code.

fig. 2The turn loop — why it never talks over itself

Upstream runs with create_response: false, so the model never answers on its own when the student pauses. The relay owns the turn: wait for the transcript (on a deadline), gate it by word count, tick the phase, and only then issue one response.create — from one call site, _advance_turn. "One open question at a time" is a property of the call graph, not a sentence in the persona. Red is the door: four ways the socket refuses.

fig. 3The landing — verdict, scorecard, and what remains

The interview closes like a real one: the student's "questions for us" reply (never word-gated) earns a spoken verdict, and only the verdict's response.done requests the scorecard — a text-only response.create in the same session, parsed defensively, never spoken, never written into the chat history. Then the record has to be true: a running row that never closes is a record that lies, so three idempotent hands close it.

Two house rules shadow every arrow here: student PII goes to a remote model only through the egress gate in app/ai/llm.py, and staff scope is decided by role — a mentor with no group sees nobody, never the whole programme. The interviewer's instructions never contain student transcript text, so rule 1 holds by shape.
